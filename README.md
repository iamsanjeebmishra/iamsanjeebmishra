## ◈ Research Experience

### AuthentiFrame — Vision-Language Deepfake Video Detection System

**April 2026 – Present**

Developing a deepfake video analysis system using the **VLAForge framework and pretrained CLIP model** for authenticity scoring, forgery localization and video-level prediction.

- Developed a deepfake video analysis pipeline using pretrained CLIP.
- Implemented video preprocessing and frame extraction using OpenCV.
- Integrated frame-level inference and video-level score aggregation.
- Evaluated the model on FaceForensics++ and Celeb-DF-v2 datasets.
- Exploring temporal consistency, prompt adaptability and robustness against compressed and low-quality videos.

**Research Results**

| Dataset | Video AUROC |
|:---|:---:|
| FaceForensics++ | **82.48%** |
| Celeb-DF-v2 | **70.80%** |
